Sistema ERP completo para varejo e serviços

Monorepo com backend Java/Spring Boot e frontend React/Vite. Cobre cadastros, estoque, compras, vendas (PDV), financeiro, ordens de serviço, produção, e-commerce e painel de funcionários, com autenticação JWT e menu por permissões.

Pacote com.temdetudo / erp DB MySQL · temdetudo_db API :8080 UI Vite + React 19

Visão geral

O projeto é um ERP operacional (“Tem De Tudo”) voltado a loja/ operação mista: produtos, estoque, compras, PDV, financeiro, OS/produção e canais de e-commerce. O frontend já mapeia uma árvore ampla de telas; o backend expõe CRUDs REST e dashboards para os domínios já modelados em JPA.

Objetivo

Operação unificada

Concentrar cadastros mestres, suprimentos, vendas, caixa, contas a pagar/receber, serviços e produção em um único sistema web autenticado.

Estado

Em evolução ativa

Há ~23 controllers e ~22 entidades no backend; o frontend possui dezenas de páginas por módulo, services dedicados, guards de rota e um framework interno em src/framework.

Acesso

JWT + perfis

Login em /api/auth, sessão stateless, BCrypt e seed de admin na primeira subida (admin / perfil ADMIN).

Arquitetura

Cliente SPA consome API REST; persistência MySQL via Spring Data JPA.

Camada web (SPA)

  • Providers: App, Auth, Theme, Menu, Sidebar, Toast, Modal…
  • Rotas públicas (login) e privadas com Layout
  • Menu lateral por módulo + permissões (`constants/menu.js`)
  • Services por domínio sob framework/todos/services
  • Exportação PDF/Excel, máscaras BR, dashboards (Recharts)

Camada API

  • Pacote raiz: com.temdetudo.erp
  • Padrão controller → repository/entity (alguns services)
  • Filtro JWT + SecurityFilterChain stateless
  • DTOs de login e dashboards (geral / financeiro)
  • Porta padrão 8080; CORS habilitado

Como rodar (local)

Pré-requisitos: Java 21, Maven, Node.js, MySQL com database temdetudo_db.

1. Backend

Ajuste usuário/senha em backend/src/main/resources/application.properties, depois:

cd backend
./mvnw spring-boot:run
# API → http://localhost:8080

2. Frontend

Opcional: defina VITE_API_URL. Em seguida:

cd frontend
npm install
npm run dev
# UI → porta Vite (padrão 5173)
